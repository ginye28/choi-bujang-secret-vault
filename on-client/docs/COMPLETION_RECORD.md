## 2. 고른 핵심 기능 3개

### 핵심 기능 1: 보안 기록 보기·AI 설명

- **제공된 부분 — 확인함:** `public/app.js`의 기록 목록, 「AI 설명 요청」 버튼, 설명 검증.
- **내가 직접 개선한 부분 — 확인함:** `student/extension.mjs`의 `renderEvents`에서 걸러 보기·상세·실패와 빈 목록 구분, `renderExplanation`에서 근거 ID 대조·규칙·확인 불가 상태 표시·제안 미실행.
- **실제 확인 결과 — 확인함:** 실제 모드 기록 칸은 연결 없음 및 `기록을 불러오지 못했습니다(기록이 없다는 뜻 아님)`이었다. 이는 실제 기록 조회 성공이나 기록 부재 확인이 아니다. 예제 모드에는 설명용 예시 기록 `event-01` 1건이 있었다. 2026-10-23 예제 모드 「AI 설명 요청」 결과 `ON_AI_PROVISIONING_PENDING`이 사유와 함께 학생 칸에 표시됐다(예제 결과).
- **잘못된 입력이나 연결 실패 때의 동작 — 확인함:** `renderEvents`는 실패와 빈 목록을 구별하고, 설명 응답 오류·잘못된 근거 ID 등 검증 불가 결과를 사용하지 않는다. 제안은 실행하지 않는다. 실제 AI·계정 연결은 확인 불가다.
- **근거(개인정보를 지운 화면, 실행 기록, 상대 경로):** 실행/화면 관찰 기록 `on-client/docs/FINISH_NOTES.md`; 함수 근거 `on-client/student/extension.mjs`의 `createStudentView`, `renderEvents`, `renderExplanation`. 별도 개인정보 제거 화면 파일 경로는 「미확인」.

### 핵심 기능 2: 업무 앱 접속 판정·상태

- **제공된 부분 — 확인함:** `public/app.js`의 앱 목록과 「… 접속 요청」 버튼.
- **내가 직접 개선한 부분 — 확인함:** `renderDecision`에서 `allow`·`deny`·`challenge`·`unknown`·요청 실패 구분, `renderStatus`에서 알림·기기·세션·연결 점검·도움정보 표시 및 도움정보 가림.
- **실제 확인 결과 — 확인함:** 실제 모드에서 `ENGINE_NOT_CONNECTED`, 접속 요청 버튼 0개였다. 따라서 실제 접속 판정은 확인되지 않았다. 예제 모드에서는 학습 자료실 `allow`, 개발 저장소 `deny`와 판정 시각을 설명용 예시 값으로 확인했다.
- **잘못된 입력이나 연결 실패 때의 동작 — 확인함:** 확인 불가 판정과 요청 실패를 허용 또는 거부 판정으로 바꾸지 않는다. 실제 연결 실패를 별도 안내한다. 실제 계정 연결·SDP 접근 제어·XDR 연결은 확인 불가 또는 미연결이다.
- **근거(개인정보를 지운 화면, 실행 기록, 상대 경로):** `on-client/docs/FINISH_NOTES.md`; 함수 근거 `on-client/student/extension.mjs`의 `createStudentView`, `renderDecision`, `renderStatus`. 별도 개인정보 제거 화면 파일 경로는 「미확인」.

### 핵심 기능 3: 설치 패키지 취약점

- **제공된 부분 — 확인함:** 「설치 패키지 조회」와 OSV 조회 서버.
- **내가 직접 개선한 부분 — 확인함:** `renderVulnerabilities`에서 조회 전·중·실패 구분, 전체 상태의 원래 값 표시, 정확한 설치 버전 행, 일부 실패 때 이미 받은 취약점 ID 유지.
- **실제 확인 결과 — 확인함:** 실제 모드와 예제 모드 모두 `not_configured`였다. 실제 OSV 조회 결과는 확인하지 않았다. `not_configured`는 취약점 없음이 아니다.
- **잘못된 입력이나 연결 실패 때의 동작 — 확인함:** 조회 실패·확인 불가·미설정 상태를 취약점 없음으로 나타내지 않는다. 허용 목록이 없어 OSV 실제 조회는 미연결이다.
- **근거(개인정보를 지운 화면, 실행 기록, 상대 경로):** `on-client/docs/FINISH_NOTES.md`; 함수 근거 `on-client/student/extension.mjs`의 `createStudentView`, `renderVulnerabilities`. 별도 개인정보 제거 화면 파일 경로는 「미확인」.

## 3. 값의 종류 구분(실제 조회·설명용 예시·미연결·확인 불가)

- **실제 조회 — 확인함:** 실제 모드 화면에서 연결 없음, 기록 불러오기 실패 문구, 업무 앱 `ENGINE_NOT_CONNECTED` 및 요청 버튼 0개, 패키지 `not_configured`를 확인했다. 실제 사건 기록·접속 판정·OSV 조회에 성공한 것은 아니다.
- **설명용 예시 — 확인함:** 예제 모드의 `event-01` 기록 1건, 학습 자료실 `allow`, 개발 저장소 `deny` 및 판정 시각. 패키지는 `not_configured`. 2026-10-23 AI 요청의 `ON_AI_PROVISIONING_PENDING`도 예제 결과다. 예제 값은 실제 조회 결과가 아니다.
- **미연결 — 확인함:** SDP 접근 제어·XDR 실제 연결은 설정 없음으로 연결 없음. OSV 실제 조회는 허용 목록이 없어 미연결. 19단계 실제 조치 집행은 미준비.
- **확인 불가 — 확인함:** 계정 연결·AI 앱 승인·실제 사건 설명은 게이트 `401 ON_APP_NATIVE_SESSION_UNVERIFIED`로 확인 불가. 예제 자료만으로 실제 연결을 확인할 수 없다.
