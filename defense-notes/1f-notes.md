최부장의 비밀창고를 내 계정에 만들기
파일을 내려받지 않습니다. 버튼 한 번이면 Vercel이 비밀창고를 내 GitHub 계정에 복사하고 인터넷 주소까지 만들어 줍니다. 10분 정도 걸립니다. 버튼을 누르기 전에 아래 순서를 먼저 읽고, 한 줄씩 따라 하세요.

최부장의 비밀창고 만들기
GitHub 계정을 준비합니다.
계정이 없으면 github.com/signup 에서 이메일, 비밀번호, 아이디를 넣고 메일로 온 인증 번호까지 입력합니다. 이미 있으면 로그인만 해 두면 됩니다.
위의 「최부장의 비밀창고 만들기」 버튼을 누릅니다.
새 탭에 Vercel 화면이 열립니다.
Vercel에 GitHub로 로그인합니다.
「Continue with GitHub」를 누릅니다. 처음이면 요금제는 무료인 Hobby를 고르고 이름을 적습니다. GitHub가 「Authorize Vercel」을 물으면 승인합니다.
저장소 만들기 화면에서 세 가지를 확인합니다.
Git Scope에 내 GitHub 아이디가 보이는지, Repository Name에 choi-bujang-secret-vault가 채워져 있는지 봅니다. 「Create private Git Repository」 체크는 꼭 해제합니다. 공개 저장소여야 심판이 볼 수 있습니다. 그다음 Create를 누릅니다.
GitHub가 Vercel 앱 설치를 물으면 허용합니다.
「Install」을 누릅니다. 저장소를 고르라고 하면 choi-bujang-secret-vault를 고르면 됩니다.
Deploy를 누르고 1~2분 기다립니다.
설정 칸은 아무것도 바꾸지 않습니다. 축하 화면이 나오면 성공입니다.
내 비밀창고 주소를 복사합니다.
「Continue to Dashboard」를 누르고 Domains에 보이는 https://…vercel.app 주소를 복사합니다. 긴 미리보기 주소가 아니라 Domains의 짧은 주소를 씁니다.
시크릿 창에서 열어 보고 제출합니다.
가짜 메모 네 건이 보이면 비밀창고가 점령된 상태로 잘 열린 것입니다. 이 카드 아래 제출 칸에 주소를 붙여 넣고 제출합니다.
