# 보너스 XDR-03 알려진 취약점 악용을 잡아 냅니다 (120점) — 카드 문구 복사 원문 ("확인:" 줄 포함)

## 이어받기
이 폴더는 내 ZTNA 판정기를 만든 같은 자료실이야. 이번에는 보너스 과제 「알려진 취약점 악용을 잡아 냅니다」를 할 거야. AGENTS.md와 README.md, 판정기 규칙 파일 위치, xdr 폴더, git 상태를 읽고 지금 판정기가 규칙을 어디서 읽는지 다섯 줄 이내로 알려 줘. 아직 아무 파일도 고치지 마.

## 만들기 1: 제작 1 · 경보 읽기
xdr/fixtures/known-cve.json 의 Wazuh 경보를 읽어 시각·출발 주소·계정·규칙 수준·설명만 뽑는 읽기 모듈을 xdr/known-cve/read-alerts.mjs 로 만들어 줘. 원본 경보는 고치지 말고, 경보에 들어 있는 비밀값처럼 보이는 값은 출력하지 마. 이 읽기 모듈은 확인용이라 decide.mjs 가 불러오지 않게 따로 둬.

확인: 경보 건수와 뽑은 줄 수가 같아야 합니다.

## 만들기 2: 제작 2 · 패턴 목록
이 공격의 알려진 형태를 xdr/known-cve/patterns.json 으로 정리해 줘. 근거는 CVE-2021-44228 형태 요청, MITRE ATT&CK T1190 이고, 신호는 요청 머리글·인자 안의 원격 조회 구문(jndi 형태), 알려진 취약점 점검 도구의 흔적 정도야. 패턴마다 이름·찾는 조건·근거 한 줄을 적고, 근거 없는 패턴은 넣지 마.

확인: 패턴마다 근거가 한 줄씩 있어야 합니다.

## 만들기 3: 제작 3 · 판단 모듈
xdr/known-cve/patterns.json 의 패턴을 xdr/known-cve/decide.mjs 파일 맨 위에 상수로 옮겨 적고, 그 패턴과 경보를 맞춰 판단하는 decide(alert) 하나를 내보내 줘. 반환은 { action: 'block' | 'alert' | 'record', confidence, reason } 모양이야. confidence(확신도)는 경보가 패턴과 얼마나 뚜렷하게 맞는지를 0~1 로 매긴 값이야. 0.85 이상이면 block, 0.5 이상이면 alert, 그 아래는 record 로 돌려줘. reason 에는 근거 패턴 이름을 한 줄로 적어. 심판은 인터넷 없이 decide.mjs 한 파일만 불러와 경보마다 바로 답을 받으니, 이 파일은 다른 파일이나 패키지를 불러오지 말고, 파일을 읽거나 쓰지도 말고, 바깥에 묻지 않고 혼자 계산해서 답하게 해 줘.

확인: 명확한 공격은 block, 애매한 건 alert, 정상 이벤트는 record 로 나뉘어야 합니다. decide.mjs 에 import 문이 없어야 합니다.

## 만들기 4: 제작 4 · 알림과 차단
xdr/known-cve/respond.mjs 를 새로 만들어, decide 결과 가운데 차단 후보만 내 ZTNA 판정기의 거부 규칙으로 넣는 연결을 만들어 줘. 규칙에는 만료 시각과 근거 경보 번호를 붙이고, 정상 사용자를 막는 규칙은 넣지 마. 알림은 같은 파일에서 xdr/alerts.log 에 한 줄씩 쌓아 줘. decide.mjs 는 판단 결과만 돌려주고 파일 쓰기·판정기 연결은 하지 않게 그대로 둬. 판정기의 기존 규칙은 고치지 마.

확인: 시험 경보를 다시 흘렸을 때 명확한 공격만 막히고 정상 요청은 통과해야 합니다.

## 만들기 5: 제작 5 · 시험 경보로 돌려 보기
npm run xdr:run -- known-cve 를 실행해서 xdr/known-cve/result.json 을 만들고, block·alert·record 건수와 정상 이벤트를 block 한 경우가 있는지 알려 줘. 정상 이벤트를 막았으면 그 경보 하나만 골라 원인을 고쳐 줘.

확인: result.json 의 counts 가 나오고, 정상 이벤트를 막은 경우가 없어야 합니다.

## 제출 전 확인
npm run xdr:run -- known-cve 를 다시 실행해 result.json 을 갱신하고, 이번 변경을 「보너스 xdr-03 저장점」으로 커밋해 줘. 커밋 뒤 block·alert·record 건수를 한 줄로 보여 줘. 오류가 나면 첫 오류만 고쳐 줘.
