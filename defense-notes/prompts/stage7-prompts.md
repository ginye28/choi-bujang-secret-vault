# 7단계 「평소와 다른 접속은 다시 확인합니다」 카드 문구 (문구 복사 원문, "확인:" 줄 포함)

## 이어받기
이 폴더는 1~6단계까지 만든 같은 자료실이야. 이번에는 7단계 「평소와 다른 접속은 다시 확인합니다」를 할 거야. AGENTS.md와 README.md, 폴더 구조, git 상태, git log -1을 읽고 README의 단계 기록이 마지막 커밋과 맞는지 대조해 줘. 어긋나면 먼저 알려 줘. 현재 기능을 다섯 줄 이내로 요약하고 다른 작업은 보존해. 아직 아무 파일도 고치지 마.

## 만들기 1: 제작 1
판정기 입력에서 엔진이 검증해 넘긴 가상 접속 정보의 출처를 구분해 줘. 지역·시각·네트워크·행동이 없거나 출처가 불명확하면 임의의 정상값으로 채우지 마. 이번에는 입력 검사만 고쳐.

확인: 위조한 클라이언트 헤더가 신뢰하는 접속 정보로 승격되지 않아야 합니다.

## 만들기 2: 제작 2
평소와 다른 시각과 처음 보는 네트워크에서 갑자기 많은 자료를 읽는 가상 사건을 추가 확인으로 보내는 규칙 하나를 판정기에 넣어 줘. 지역 하나만으로 영구 차단하지 말고 사유를 남겨. 기존 기기 규칙은 유지해.

확인: 정해진 복합 사건은 추가 확인, 정상 사건은 허용으로 나와야 합니다.

## 만들기 3: 제작 3
제공 엔진이 같은 내 로그인으로 다시 로그인한 시각을 확인하는 계약이 있는지 먼저 봐 줘. 있으면 확인 전 자료를 막고 새 로그인 뒤 요청을 다시 판정해. 아직 없으면 가상 사건 규칙만 시험하고 실제 자료 차단은 미실행으로 남겨. 토큰 원문은 기록하지 마.

확인: 계약이 준비된 환경에서만 다시 로그인 전 차단과 새 요청 허용을 실측합니다.

## 제출 전 확인
이번 변경을 「7단계 저장점」으로 커밋해 줘. 그다음 npm run bundle을 실행해 제출 묶음 JSON과 요약을 보여 줘. 오류가 나면 첫 오류만 고쳐 줘.
