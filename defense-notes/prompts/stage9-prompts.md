# 9단계 「도플갱어를 찾고 권한을 거둡니다」 카드 문구 (문구 복사 원문, "확인:" 줄 포함)

## 이어받기
이 폴더는 1~8단계까지 만든 같은 자료실이야. 이번에는 9단계 「도플갱어를 찾고 권한을 거둡니다」를 할 거야. AGENTS.md와 README.md, 폴더 구조, git 상태, git log -1을 읽고 README의 단계 기록이 마지막 커밋과 맞는지 대조해 줘. 어긋나면 먼저 알려 줘. 현재 기능을 다섯 줄 이내로 요약하고 다른 작업은 보존해. 아직 아무 파일도 고치지 마.

## 만들기 1: 제작 1
제공된 가상 사건에서 가명 사용자·기기·요청 종류·판정만 읽도록 판정기 입력을 정리해 줘. 메모 내용·토큰·실명은 저장하거나 출력하지 마. 이번에는 입력 처리만 바꿔.

확인: 정상 사건과 의심 사건을 비밀값 없이 읽을 수 있어야 합니다.

## 만들기 2: 제작 2
평소와 다른 네트워크와 갑작스러운 다량 조회가 함께 나타날 때만 의심으로 표시하는 탐지 규칙 하나를 넣어 줘. 지역 하나만으로 확정하지 말고 정상 사건은 그대로 두어.

확인: 복합 의심 사건만 탐지되고 정상 사건은 유지되어야 합니다.

## 만들기 3: 제작 3
탐지한 사건의 별도 결과에 propose_revocation 제안을 넣어 줘. 대상은 확인된 가상 기기 한 개로 한정하고 이유 코드를 함께 남겨. 기존 접속 허용/거부 응답 형식은 바꾸지 마. 회수 API를 직접 만들거나 기기 권한을 임의로 바꾸지 마. 실제 회수와 시간은 심판이 확인해.

확인: 의심 사건은 대상과 이유가 있는 회수 제안을 내고 정상 사건은 내지 않아야 합니다.

## 제출 전 확인
이번 변경을 「9단계 저장점」으로 커밋해 줘. 그다음 npm run bundle을 실행해 제출 묶음 JSON과 요약을 보여 줘. 오류가 나면 첫 오류만 고쳐 줘.
