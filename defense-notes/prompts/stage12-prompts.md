# 12단계 「탈환 작전실을 완성합니다」 카드 문구

## 이어받기
이 폴더는 1~11단계까지 만든 같은 자료실이야. 이번에는 12단계 「탈환 작전실을 완성합니다」를 할 거야. AGENTS.md와 README.md, 폴더 구조, git 상태, git log -1을 읽고 README의 단계 기록이 마지막 커밋과 맞는지 대조해 줘. 어긋나면 먼저 알려 줘. 현재 기능을 다섯 줄 이내로 요약하고 다른 작업은 보존해. 아직 아무 파일도 고치지 마.

## 만들기 1: 제작 1
탈환 작전실에 판정기 규칙, 탐지 사건, 회수 상태, 복구 버전의 요약을 보여 줘. 실제 API 응답에서 확인된 결과와 미실행을 구분하고 가상 메모 본문은 표시하지 마.

확인: 화면의 수치와 가린 서버 기록이 서로 맞아야 합니다.

## 만들기 2: 제작 2
1~11단계의 정상·금지 요청, 기대 결과, 실제 API 결과, 요청 ID, 확인 시각을 한 표로 만드는 절차를 붙여 줘. 아직 실행하지 않은 41종 시험을 임의로 통과 처리하지 마.

확인: 금지 요청 거부와 정상 요청 허용이 모두 실측 결과로 남아야 합니다.

## 만들기 3: 제작 3
검사한 커밋을 기준으로 학생 판정기·탐지 규칙·접속 앱·자료실의 설치·실행·중지·복구 안내를 README에 적어 줘. 엔진은 ALEPH SDP 엔진 사용으로 출처를 밝히고 비밀값은 포장하지 마.

확인: 학생 몫과 제공 엔진의 출처가 구분되고 재현 순서가 있어야 합니다.

## 제출 전 확인
이번 변경을 「12단계 저장점」으로 커밋해 줘. 그다음 npm run bundle을 실행해 제출 묶음 JSON과 요약을 보여 줘. 오류가 나면 첫 오류만 고쳐 줘.

## 직접 확인할 것

- 제공 엔진과 학생 작업의 출처를 밝혔는가?

## 이번 단계 괴물 (카드)
- 광주의 1첩반상무: 인증 조회와 타인 메모 조회를 같은 제출본에 연속 전송
- 천안의 천안호날두과자미: 미등록 기기 요청 뒤 회수된 신원으로 다시 전송
- 양양의 양양송이버섯고양이: 복구 뒤 서명 없는 변경 요청과 구역 밖 조회를 전송

## 결과·메모
- 판정: **100 / 100** (커밋 `677da0f`, 2026-10-13). 전체 1,200 / 1,200, 잡은 괴물 41 / 41.
- 점수 흐름: 0 → 38 → 45 → 53 → **100** (자세한 표는 `ALEPH-방어전-진행기록.md` 4절).

### 이 카드 문구만으로는 부족했던 부분 (실제로 필요했던 것)
1. **요청과 점검 이름(attackId) 연결** — fetch 옵션 `alephEvidence: { caseId, requestKey: 'read' }`. 카드·판정 안내에는 없고, 운영자의 공개 표본 저장소 `ChoiTimo/byteback-sample-pass` 에 있다.
2. **`observed` 는 관측 사실만** — `HTTP 401; method=GET` (허용 항목: HTTP 상태, bodyBytes, jsonArrayLength, jsonReady, method, urlSha256). 결과는 `attackId·stage·expected·observed·result`.
3. **미실행 구별** — 보내지 않은 시험도 `observed`·`result` 를 `not_run` 으로 묶음에 적고, 41종 기준 수치(실행·막음·미실행)를 화면과 `GET /api/checks` 에 같은 기록으로 표시. 코드 시험은 실제 API 실행으로 세지 않음.
4. **「100점 받는 법」**(과제 카드에 나중에 추가) — 기본 70 + `npm install` 무오류 / `decide()` 가 형식 오류 요청에도 5개 이름 거부 응답 / `step` ≥ 12 각 10점.

### 카드의 "확인:" 줄과 실제 판정 조건 매핑
- 「실행 기록 대조」: 요청이 attackId 와 연결돼 있고 `observed` 가 허용 항목만 담는가
- 「기록과 화면 수치」: 화면 수치 = 서버/제출 기록에서 센 값 (`/api/checks`, `/api/ops`)
- 「미실행 구별」: 보내지 않은 시험이 `not_run` 이고 막음·통과로 세어지지 않는가
- 제출은 반드시 **GET 요청만** (쓰기 요청이 있으면 0점).
