# 8단계 「자료마다 갈 수 있는 구역을 나눕니다」 카드 문구 (문구 복사 원문, "확인:" 줄 포함)

## 이어받기
이 폴더는 1~7단계까지 만든 같은 자료실이야. 이번에는 8단계 「자료마다 갈 수 있는 구역을 나눕니다」를 할 거야. AGENTS.md와 README.md, 폴더 구조, git 상태, git log -1을 읽고 README의 단계 기록이 마지막 커밋과 맞는지 대조해 줘. 어긋나면 먼저 알려 줘. 현재 기능을 다섯 줄 이내로 요약하고 다른 작업은 보존해. 아직 아무 파일도 고치지 마.

## 만들기 1: 제작 1
내 자료실의 메모와 강사 공지를 서로 다른 자원 ID로 표시해 줘. 기존 자료와 주소는 보존하고, 화면 메뉴 변경은 이번 요청에 넣지 마.

확인: 요청마다 서버가 구별할 수 있는 자원 ID가 있어야 합니다.

## 만들기 2: 제작 2
판정기에 자기 메모 읽기·수정과 강사 공지 수정의 구역 규칙을 넣어 줘. 엔진이 확인한 사용자·기기·메서드·정확한 경로를 사용하고 알 수 없는 경로는 거부해. 쿼리로 기능을 고르지 말고 자료 ID만 고르며, :id와 같은 깊이에 export 같은 기능 경로를 두지 마. 이전 규칙은 유지해.

확인: A 자기 메모는 허용, B의 A 메모와 일반 학생의 공지 수정은 거부되어야 합니다.

## 만들기 3: 제작 3
자료 API에서도 검증된 사용자와 저장된 소유자·강사 권한을 다시 대조해 줘. 화면 메뉴나 요청 본문의 role을 믿지 말고 거부 사유를 짧게 남겨. 이번에는 API 확인만 추가해.

확인: 메뉴를 우회한 직접 API 요청에서도 다른 구역 자료가 나오지 않아야 합니다.

## 제출 전 확인
이번 변경을 「8단계 저장점」으로 커밋해 줘. 그다음 npm run bundle을 실행해 제출 묶음 JSON과 요약을 보여 줘. 오류가 나면 첫 오류만 고쳐 줘.
